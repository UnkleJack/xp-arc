# XP-Arc Verification Suite
*Tests Proving Protocol and Runtime Behavior*

This directory contains the verification tests for the XP-Arc multi-agent pipeline. Rebuilders can use these tests to validate that their scratch-built implementations comply with the core protocol guarantees.

---

## Running the Tests

To run the verification suite, install `pytest` and execute it from the repository root:

```bash
pip install pytest
pytest
```

---

## Test Catalog

### 1. `test_dossier.py`
- **Focus**: Verifies identity profiles and dossiers generated by `TheDossier` station.
- **Assertion**: Ensures dossier entities conform to schema structures and parse correctly.

### 2. `test_fracture.py`
- **Focus**: Verifies the Cognitive Sharding protocol (`FractureProtocol` in `xp_arc/core/fracture.py`).
- **Assertion**: Tests that:
  - Shards are successfully created with linked `fracture_id` and `parent_task_id`.
  - Stale or partial shard states block stitching.
  - Completed shards are successfully stitched back into a single mapped entity.

### 3. `test_osint.db` & `test_osint.py`
- **Focus**: Verifies standard entity lookup, classification, and OSINT pipeline flows.
- **Assertion**: Evaluates domain extraction, relationship mapping, and edge insertions.

### 4. Stress Tests (`stress_test.py` & `stress_test_instrumented.py`)
- **Focus**: Performance boundary validation under massive cascading spawns (Snowball protocol).
- **Assertion**: Ensures:
  - SQLite WAL is resilient under high-frequency writes.
  - Lineage tracking accurately blocks cascade chains exceeding 5 levels deep.
  - Entities count limit (`max_entities = 500`) prevents infinite snowballing loops.
