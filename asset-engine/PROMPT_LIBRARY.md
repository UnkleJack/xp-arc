## PLATFORM-SPECIFIC NOTES

### ChatGPT (DALL-E 3)
- Paste full prompt (positive + negative combined)
- DALL-E 3 ignores explicit negative prompts but follows "avoid" language
- Best for: coloring pages, planner pages, simple compositions
- Limit: ~2-3/day free tier

### [PERSON_NAME] (Image Gen)
- Supports explicit negative prompt field (use the NEGATIVE section)
- Excellent for: tarot cards, detailed illustrations, art nouveau
- More generous free tier
- Handles aspect ratios well

### Copilot Designer (DALL-E 3)
- Same as ChatGPT but Microsoft account
- 15 generations/day free
- Good backup when ChatGPT rate limited

### Grok (X)
- Limited free access
- Good for: quick iterations, fun variations
- Less consistent for specific styles

### Fal.ai / Replicate (API)
- Use with the structured prompts (positive + negative separated)
- Flux-dev for general, Flux-schnell for speed
- Midjourney v6 on Replicate for tarot (if budget allows)
- Best for: sprite sheets, high-volume, consistent quality

### Local ComfyUI (zo.computer)
- Full control, LoRA support
- Install simpsons-lora + disney-lora for style consistency
- Unlimited generations
- Best for: final production runs, sprite sheets, style locking

## VARIATION STRATEGY (For Evolution)

For each concept, generate 3 variants by tweaking:

**Variant 1 — Base** (use prompts exactly as written)

**Variant 2 — Emphasis Shift**
Add to positive: "extreme close-up, detailed face, hyper-detailed linework"
Add to negative: "full body, wide shot, distant"

**Variant 3 — Style Push**
Add to positive: "masterpiece, best quality, ultra-detailed, 8k resolution"
Add to negative: "amateur, beginner, rough draft, sketch"

**Variant 4 — Composition Shift**
Add to positive: "dynamic pose, dramatic angle, rule of thirds"
Add to negative: "static pose, front view, centered, boring composition"

**Variant 5 — Wildcard**
Add to positive: "[random element: fog, lightning, candles, roses, thorns, moonlight]"
Keep negative same

## REVIEW CHECKLIST (For Your Obsidian Vault)

When reviewing each batch, rate 1-5 on:

- [ ] **Style Consistency** — Looks like the target style (Simpsons/Disney)?
- [ ] **Line Quality** — Clean, closed paths (coloring) or elegant variable weight (Disney)?
- [ ] **Concept Clarity** — Recognizable subject at thumbnail size?
- [ ] **Print Readiness** — No artifacts, proper contrast, correct aspect ratio?
- [ ] **Creative Spark** — Has that "something special" beyond competent execution?

Tag in Obsidian:
- `#approved` — Keep, add to training set
- `#rejected` — Discard, note why in frontmatter
- `#revise` — Close but needs tweaking (note what)
- `#style:simpsons-horror` or `#style:disney-dark`
- `#type:coloring` / `#type:tarot` / `#type:planner` / `#type:sprite`
