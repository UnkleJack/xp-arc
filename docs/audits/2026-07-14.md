## Detail

### CRITICAL-1 / CRITICAL-3: API and key exposure — Fixed
- The daemon binds `127.0.0.1` by default. With `XP_ARC_API_KEY` set, every route except `/api/health` requires a bearer token (`run_persistent.py`, `auth_middleware`).
- `export_state()` strips `hmac_key` from station rows (`xp_arc/core/pool.py`).
- Station keys live in a per-database key file, encrypted when `XP_ARC_MASTER_KEY` is set.
- Keys committed in early history were tied to throwaway Gauntlet and dev databases and are dead. Any database still holding them should be discarded.
- *Tests:* `tests/test_hmac_key_exposure.py`, `tests/test_security_hardening.py`.

### CRITICAL-2: Unkeyed writes — Partial
- A station that has a key must present a valid MAC. Unknown station IDs are rejected.
- **Remainder:** four internal identities (`legacy_local`, `executive`, `aboyeur`, `fracture_protocol`) may still write without a key. Every such write is logged as `legacy_write` (RT-18). About 40 call sites write without naming a station. Closing this means giving the internal writers keys and routing those call sites through `station_writer()`. That is an auth-contract change and needs its own decision.

### CRITICAL-4: QA binding — Fixed
- `Aboyeur.validate_and_sign()` requires `pending_qa`, binds `entity_type`/`entity_value` to the stored entity, and signs with real HMAC-SHA256.
- There is no default signing key: a missing `XP_ARC_ABOYEUR_KEY` raises (`xp_arc/core/aboyeur.py`).

### CRITICAL-5: Pre-QA side effects — Fixed
- Forager, Analyst, Amphithere, Cartographer and Salamander no longer write inside `process()`. They return `spawn_targets` and `edges`, which the Executive commits only after Aboyeur approval (`ExecutiveChef._process_spawns`, `_commit_edges`).
- Edges are capped at `MAX_EDGES_PER_ENTITY`.
- *Tests:* `tests/test_post_qa_commit.py`.
- Findings (`add_finding`) are still written during processing. They are observations, not graph data.

### CRITICAL-6: SSRF — Fixed
- `xp_arc/core/network_guard.py` resolves each host and rejects any address that is not public. Redirects are not followed (`NoRedirectHandler`).
- `/api/seed` and the Forager share the same guard.

### HIGH-1: Duplicate claims — Fixed
- `IntelligencePool.claim_entity()` performs a single `UPDATE … WHERE status = 'raw'` and checks the row count.

### HIGH-2: Retry budget — Fixed
- `ExecutiveChef._qa_gate_with_retry()` drives the `max_rejections` budget, with `RETRY_HARD_CAP` as a backstop.
- *Tests:* `tests/test_retry_and_escalation.py`.

### HIGH-3: Safe halt ingestion — Fixed
- `PersistentKitchen` refuses seeds while halted and during the veto window; `POST /api/seed` returns 503. The halt is logged once.
- *Tests:* `tests/test_audit_2026_07_14.py`.
- The halt flag is in-process. A restart resumes ingestion, and the debt grace window applies.

### HIGH-4: Seed lineage — Fixed
- A seed with any non-zero `cascade_depth`, a `root_task_id`, or a `spawn_chain` is rejected. `root_task_id` is set to the seed's own ID inside the insert transaction.

### HIGH-5: Descendants — Fixed
- `get_descendants()` walks integer `parent_task_id` links with a recursive CTE, so the whole subtree is returned and look-alike IDs never match.
- *Tests:* `tests/test_audit_2026_07_14.py`.

### HIGH-6: Fracture bounds — Fixed
- Non-positive shard counts are refused before the parent moves. Counts above `MAX_SHARD_COUNT` are clamped.
- A permanently stranded group escalates to the Chef de Cuisine through the `fractured → failed` exit.
- `authorize_fracture()` now delegates to the Aboyeur's rule.

### HIGH-7: CI and broker — Partial
- CI runs `bandit -r xp_arc` and the full suite.
- **Remainder:** `xp_arc/broker.py` and `broker_client.py` are ruled obsolete but still in the tree, including a hard-coded local import path. They are not loaded by any runner. Removing them is tracked in `STATUS.md`.

### MEDIUM-1: Timestamps — Fixed
- `assigned_at`, `completed_at` and `created_at` come from SQLite `datetime('now')`.
- The Aboyeur signature payload carries a process-clock timestamp. It acts as a nonce and is not a lifecycle timestamp.

### MEDIUM-2: Dossier inputs — Fixed
- `TheDossier._gather_intelligence()` cites only completed, Aboyeur-signed entities.
- *Tests:* `tests/test_audit_2026_07_14.py`.

### MEDIUM-3: HTTP API exhaustion — Partial
- The daemon runs on aiohttp, whose default request body cap is 1 MiB. `/api/seed` is rate-limited and validated.
- **Remainder:** `/api/dragon` and `/ws` serialize the whole pool on every request or push, with no pagination.

### MEDIUM-4: Provenance — Fixed
- Edges are declared independently of entity dedup. `add_edge()` skips exact duplicates, so a domain linked from several pages keeps one edge per page.
- *Tests:* `tests/test_post_qa_commit.py`.

### MEDIUM-5: `prompt_version` — Fixed
- `entities.prompt_version` is recorded on every completion: the station's `prompt_version` (default `rules-v1`), or a per-output override. Older databases are migrated on open.
- *Tests:* `tests/test_audit_2026_07_14.py`.

### LOW-1: Test and migration hygiene — Partial
- Most tests use `TemporaryDirectory` fixtures and close their pools. Later migrations check `PRAGMA table_info` per column.
- **Remainder:** three test call sites still use `tempfile.mktemp()` (`tests/test_red_team.py`, `tests/test_load.py`). The original lineage migration still adds `root_task_id`, `cascade_depth` and `spawn_chain` as a group.
