# xp-arc-hardened Constitution

## Principles
- No explicit principles extracted from AGENTS.md/SOUL.md. Please add guiding principles here.

## Amendment Process
1. Propose changes via an issue describing the proposed amendment.
2. Team discusses and reaches rough consensus.
3. Submit a pull request with the changes to this constitution.
4. Maintainers review and merge if approved.

## Enforcement Hooks
- This constitution is enforced via CI: a script checks for compliance on each PR.
- Any contribution that violates the principles will be blocked until compliance is achieved.
- The constitution itself can be amended following the above process.
